# Drive

Personal organization folder for the major project — not part of the `major project` git repo, since these are uploaded documents (PDFs, Word docs) rather than code.

## Structure

- `01-research-papers/`
  - `papers/` — the actual paper PDFs.
  - `research-papers-summary.docx` — one single document with every paper's full summary (grouped by publisher), instead of a separate file per paper.
  - `research-papers-summary-v2.docx` — a quick-scan companion: one table, one row per paper (title, authors, year, publisher, one-line relevance). Regenerate both whenever papers are added or removed, rather than adding more files.
- `02-kavita-maam-documents/` — documents from/for Kavita ma'am.
- `03-docs-presentation/` — Wednesday presentation material for sir, as documents rather than slides. Suggested naming: `2026-08-05-update.docx` (date first, sorts chronologically).
- `04-minutes-of-meeting/` — Wednesday meeting minutes. Suggested naming: `2026-08-05-mom.md` (or `.docx`).

Upload files into the matching folder as you go.
